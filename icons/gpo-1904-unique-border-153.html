Use this icon in HTML

Download every part: Web bundle ZIP 1 of 3 Web bundle ZIP 2 of 3 Web bundle ZIP 3 of 3. Extract all parts into the same folder, then place the collection folder beside your HTML file. Together the parts include all SVGs, PNGs, fonts, CSS, instructions and license notices. Keep the subfolders together for these examples.

Three-tone image

This displays all three tones with a transparent background. Set the height; the width follows the original proportions.

<img src="collection/gpo-cuts-1904/svg/multitone/gpo-1904-unique-border-153.svg"
     alt="Six dark teardrops with outlined leaves and fine rays" height="96">

An image has its own colour context, so page CSS cannot recolour its internal regions. For a decorative image beside a text label, use alt="".

Three-tone with your own colours

On an HTTP(S) page, load the sprite from the same site. This complete example uses dark primary ink and two strengths of red. Each region has an independent colour and opacity; set the secondary and tertiary values alike for a two-tone appearance.

<style>
  .revival-cut {
    display: inline-block;
    font-size: 96px;
    height: 1em;
    width: 0.859375em;
    vertical-align: middle;
    --fr-primary-color: #24251f;
    --fr-secondary-color: #a5422c;
    --fr-tertiary-color: #a5422c;
    --fr-primary-opacity: 1;
    --fr-secondary-opacity: 0.55;
    --fr-tertiary-opacity: 0.25;
  }
</style>
<svg class="revival-cut" role="img" aria-label="Six dark teardrops with outlined leaves and fine rays">
  <use href="collection/gpo-cuts-1904/web/icons-multitone-6.svg#gpo-1904-unique-border-153"></use>
</svg>

Monochrome icon font

Copy the whole web/ folder, including CSS and webfonts. Font size and colour use ordinary CSS. The icon font draws the solid version; use SVG for three-tone artwork.

<link rel="stylesheet" href="collection/gpo-cuts-1904/web/icons.css">
<span class="fr-icon fr-gpo-1904-unique-border-153" aria-hidden="true"
      style="font-size:96px;color:#a5422c"></span>
<span>Six dark teardrops with outlined leaves and fine rays</span>

The decorative font icon is hidden from screen readers and has a visible text label. An icon conveying meaning on its own needs role="img" and an aria-label instead of aria-hidden.
